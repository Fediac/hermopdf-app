What rights does GPL-3.0 give you?

  • Use the program for any purpose, free of charge.
  • Read, modify and build the code yourself.
  • Distribute your modified version under GPL-3.0.

Why does an open-source program have Pro?

The GPL allows paid distribution.

  • The free version is a complete PDF editor: reading, editing, compressing to a target size, merging, splitting, signing and basic conversions.
  • Pro adds OCR, batch processing and saved workflows and is unlocked with a license key in the official build.
  • Its real job is funding development: no ads, no data sales.

Trademark

The code is free, but the "HermoPDF" name and logo are reserved as trademarks. If you fork and distribute the code, please use a different name and logo.

How is it built and tested?

HermoPDF is developed by a single developer (Fediac) at NorthLightPixels, with help from AI coding assistants. Features are checked with automated tests that use the app the way a person would. The screenshots and compression numbers on this site also come from the app itself, using synthetic test documents.

Contributing and components

Bug reports, translation suggestions and code contributions are welcome on GitHub (CONTRIBUTING.md). We build on open-source projects such as Electron, pdf.js, pdf-lib and Tesseract; their license notices ship with the program.
