Why does Windows say "Windows protected your PC"?

HermoPDF is currently published without a code-signing certificate; these are expensive for an independent developer. SmartScreen warns about unsigned programs few people have downloaded yet. It does not mean "virus found", only "I do not recognise this file yet".

What should you do?

  1. Check that the file really came from us (below).
  2. In the warning, click More info.
  3. Check that the publisher is "Unknown publisher" and the file name is {{cfg:release.fileName}}, then click Run anyway.

If Smart App Control is on in Windows 11, unsigned programs may be blocked entirely. We do not recommend switching it off; waiting for a code-signed release is safer. A code-signed release is high on our list.

How to verify the file you downloaded

  1. Open Command Prompt.Type cmd in the Start menu and press Enter.
  2. Run this command(if the file is in your Downloads folder):
    certutil -hashfile "%USERPROFILE%\Downloads\{{cfg:release.fileName}}" SHA256
  3. Compare the result with the SHA-256 above.If every character matches, it is our file. If not, do not run it, and let us know.

Antivirus programs sometimes flag new unsigned programs by mistake; if you see that, tell us.
